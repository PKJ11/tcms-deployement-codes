The event log still says Program C:\Program Files\nodejs\node.exe for service TCMS — that means the reinstall to cmd.exe never actually happened, this is still the original broken config. And the log file is missing because the logs folder doesn't exist yet (NSSM won't create missing directories). Let's do this in order, precisely:

# 1. create the logs folder first — NSSM won't create it for you
New-Item -ItemType Directory -Force -Path "C:\Users\Administrator\Desktop\tcms-qbd-main\logs"

# 2. fully remove the broken service
nssm stop TCMS
nssm remove TCMS confirm

# 3. reinstall pointed at cmd.exe, not node.exe directly
nssm install TCMS "C:\Windows\System32\cmd.exe" "/c npm start"
nssm set TCMS AppDirectory "C:\Users\Administrator\Desktop\tcms-qbd-main"
nssm set TCMS AppEnvironmentExtra NODE_ENV=production
nssm set TCMS AppExit Default Restart
nssm set TCMS AppRestartDelay 5000
nssm set TCMS AppStdout "C:\Users\Administrator\Desktop\tcms-qbd-main\logs\tcms-out.log"
nssm set TCMS AppStderr "C:\Users\Administrator\Desktop\tcms-qbd-main\logs\tcms-err.log"

# 4. start and check
nssm start TCMS
Start-Sleep -Seconds 5
Get-Service TCMS

Then, regardless of whether it's now Running or Paused again:
Get-Content "C:\Users\Administrator\Desktop\tcms-qbd-main\logs\tcms-err.log" -Tail 30

Paste back the Get-Service TCMS result and that log tail — if cmd.exe /c npm start still fails, the log will finally show us Node/Next's actual error message instead of just "exited with code 1."
